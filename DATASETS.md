# Chat corpora — overview & confounds

A short field guide to the datasets we use (or might use) for stylistic
analysis. The point is to make confounds legible *before* we run a measurement
and discover that the effect we attributed to a model was really a property of
the user population, the collection UI, or the filter pipeline.

## What each one actually is

### WildChat-1M  (`allenai/WildChat-1M`)
Conversations logged from a free public chat UI on Hugging Face Spaces. Users
got GPT-3.5 / GPT-4 access in exchange for consent to log. 1.0M conversations
total, 838k after toxic content is removed. 68 languages. PII de-identified
with Microsoft Presidio plus hand-written rules. Released under ODC-BY; the
non-toxic split is freely downloadable, the *full toxic* split requires
approval. Timestamps start April 9, 2023.

- **Strong**: real human prompts, multi-turn, broad demographic spread,
  timestamped, well-documented schema.
- **Confounds**: only OpenAI models, only a population willing to use a free
  generic chat tool (skews toward jailbreaks, NSFW, students, multilingual
  users). Toxicity/redaction filters were applied — measurements of taboo
  content in the standard release are filter-shaped.

### ShareGPT V3 (Vicuna unfiltered raw)
Aggregation of ChatGPT conversations that users voluntarily shared via the
ShareGPT browser extension. Used as Vicuna training data. The
`ShareGPT_V3_unfiltered_cleaned_split.json` file contains ~53k cleaned
conversations (down from ~100k raw, after dropping non-English, "AI
moralizing" phrases, and other heuristics) and the conversations are then
split into 2048-token chunks, so the JSON has more *items* than
*conversations*. Schema is messy (roles vary: `human/gpt/chatgpt/bing/bard`).

- **Strong**: large, diverse domains, real user prompts.
- **Confounds**: severe self-selection — people share what they find
  noteworthy, funny, or impressive. Model field is not reliable; you usually
  can't tell which OpenAI model generated a given turn. Some conversations
  contain leakage of system prompts or screenshots-as-text. Date metadata
  is mostly absent.

### UltraChat  (`stingning/ultrachat`, also `HuggingFaceH4/ultrachat_200k`)
**Fully synthetic.** Both the "user" and the "assistant" turns were generated
by GPT-3.5-turbo, prompted by topic seeds. Full release is ~1.5M dialogues;
the H4 200k subset (207,865 train + 23,110 test) is a heavily filtered version
used for training Zephyr and similar models.

- **Strong**: clean, large, topic-balanced.
- **Confounds**: the "user" side is a model imitating a user — *do not* use
  this to study human prompt style. Stylistic features measured here reflect
  GPT-3.5's prior over both speakers, not anything about real humans.

### LMSYS-Chat-1M  (`lmsys/lmsys-chat-1m`)
Logs from Chatbot Arena (anonymous A/B comparison) and direct chat collected
April–August 2023. 1.0M conversations across 25 models from multiple vendors,
with model identity recorded per turn. ~210k unique users (by IP), 154
languages, average 2.0 turns per conversation. Names redacted as
`NAME_1`, `NAME_2`, etc. Gated.

- **Strong**: the only large public corpus where you can compare cross-vendor
  model styles on *the same prompt distribution*.
- **Confounds**: Arena prompts skew toward eval-flavored asks ("write a poem
  about X", trick questions, jailbreaks) because users are deliberately
  comparing models. Not representative of natural usage.

### WildChat-4.8M-Full  (`allenai/WildChat-4.8M-Full`)
Same collection apparatus as WildChat-1M, but covering a longer window and
including the toxic-flagged conversations. ~4.8M conversations across more
GPT-3.5/4 checkpoints. Same population (free-tool volunteers), same redaction
pipeline. Gated with **manual** approval (not just terms acceptance).

- **Strong**: superset of WildChat-1M; useful for a longer time window and for
  studying filtered-out toxic content explicitly.
- **Confounds**: same as WildChat-1M, plus the toxic split has its own
  selection effects (jailbreaks and edge prompts are over-represented).

### Chatbot Arena 33K  (`lmsys/chatbot_arena_conversations`)
Earlier, smaller Arena-vote release: ~33k pairwise conversations where the
same prompt is sent to two models, with the human vote attached. 20 models,
April–June 2023. Gated.

- **Strong**: paired same-prompt comparisons with human preference labels.
  Cleaner than LMSYS-Chat-1M for *pairwise* model-style comparisons.
- **Confounds**: Arena-style prompt distribution; vote is a single noisy
  signal; smaller volume.

### arena-human-preference-140k  (`lmarena-ai/arena-human-preference-140k`)
Larger, more recent pairwise Arena preferences from `lmarena-ai`. ~140k
prompt-and-pair rows with the human vote. CC-BY-4.0, public.

- **Strong**: bigger, newer, public version of the paired Arena format.
  Useful for cross-model style comparison at scale without gating.
- **Confounds**: same Arena prompt-distribution skew as the 33k release; voter
  noise; model identities are sometimes anonymized at vote time.

### PRISM  (`HannahRoseKirk/prism-alignment`)
1,500 participants from 75 countries, each given paired demographic surveys
*and* logged conversations across 21 models, with per-utterance ratings.
Released as four jsonl files (`survey`, `conversations`, `utterances`,
`metadata`). CC-BY.

- **Strong**: only release we know of that pairs structured human
  demographics + value surveys with multi-model conversations + per-message
  ratings. The right corpus for "does style preference vary with who the
  user is".
- **Confounds**: small (~8k conversations, ~68k utterances). Participants
  were paid and told what they were doing, so the prompt distribution is
  prompted-by-the-study, not organic.

### claude.ai personal export
Your own conversations exported from claude.ai settings.

- **Strong**: ground truth for one human × multiple Anthropic models over
  time. You know the user (yourself), you know roughly when each model was
  current, you have project/system-prompt context.
- **Confounds**: n=1 user. Style measurements collapse "Claude's style" with
  "how this one person talks to Claude" and "what topics this person brings
  up." Generalize cautiously.

### OpenAssistant (OASST1 / OASST2)
Crowdworker-built **conversation trees**, where the same volunteers wrote both
prompter and assistant turns and rated each other's writing. OASST1 has
66,497 trees / 161,443 messages (full) or 10,364 / 88,838 in
`ready_for_export`; OASST2 has 70,642 / 208,584 (full) or 13,854 / 135,174
(`ready_for_export`). The `ready_for_export` subsets are the curated "good"
slice.

- **Strong**: high-quality, multilingual, openly licensed.
- **Confounds**: the "assistant" turns are *humans pretending to be a helpful
  assistant*, not model outputs. Useful for studying what humans think
  assistants should sound like — not for studying what models actually sound
  like.

### HH-RLHF (Anthropic helpful + harmless)
~161k pairs of model responses rated by Surge crowdworkers, used to train
early preference models. The model on the other end predates the public
Claude API.

- **Strong**: well-known baseline for RLHF research, clean schema.
- **Confounds**: model is pre-Claude and not identified per-sample;
  conversations are short and task-narrow (helpfulness probes, red-team
  attempts). Crowdworker register dominates the human side.

## Confound checklist before comparing across datasets

When a stylistic difference shows up, walk through these before attributing
it to a model:

1. **Who is the human?** Single user (claude.ai export), self-selected
   sharers (ShareGPT), free-tool volunteers (WildChat), crowdworkers (HH-RLHF,
   OASST), Arena testers (LMSYS), or no human at all (UltraChat)?
2. **Who is the model?** Single vendor (WildChat = OpenAI, claude.ai =
   Anthropic), multi-vendor (LMSYS), or human-as-model (OASST)?
3. **What is the collection UI shaping?** A "share this cool reply" extension
   biases toward impressive outputs; an Arena UI biases toward eval-style
   prompts; a personal export contains whatever you happened to ask.
4. **What was filtered out?** WildChat redacts PII and flags toxicity;
   UltraChat-200k is a *post-hoc filtered subset*; ShareGPT was lightly
   cleaned by the Vicuna team.
5. **What time period?** Model behavior drifts across versions; "GPT-4 in
   WildChat" is several different checkpoints. Date the slice if possible.
6. **Are turn-level metadata reliable?** ShareGPT model labels are not;
   WildChat and LMSYS labels are.

## Mapping to the scripts in this repo

- `extract_wildchat_assistant_messages.py` → WildChat-1M (Arrow IPC reader)
- `extract_sharegpt_ultrachat_assistant_messages.py` → ShareGPT, UltraChat
- `download_datasets.py` → fetches all of the above plus WildChat-4.8M-Full,
  LMSYS-Chat-1M, PRISM, Chatbot Arena 33K, and arena-human-preference-140k

The newer datasets (WildChat-4.8M-Full, LMSYS-Chat-1M, Chatbot Arena 33K,
arena-human-preference-140k, PRISM) are pulled as native HF snapshots
(parquet / jsonl) rather than converted to Arrow IPC. They do not yet have
extract scripts in this repo — the existing `pa.ipc.open_stream` reader will
not work on parquet. claude.ai exports, OASST, and HH-RLHF likewise need
their own readers.

## Per-study confound notes

Beyond the general confound checklist above, individual studies surface
dataset-specific instrument problems that future readers should know about.

### Profanity-first study → `profanity/`

Full treatment (instrument, methodology, lessons) lives in the `profanity/`
subproject (`profanity/methodology.md`, `profanity/phase_a_prism.md`). Dataset
eligibility found for assistant-first profanity:

- **PRISM-alignment** — runnable but **floored + topic-confounded**: its
  sensitive-topic distribution (LGBTQ+, abortion, sex ed) makes a flat wordlist
  fire ~90% on legitimate clinical usage, and genuine assistant-first vulgar use
  is ~0%, so PRISM can't answer the question. (`if_chosen` also adds a
  within-dataset selection confound atop the documented paid+prompted effect.)
- **arena-human-preference-140k** — *not used*: no Claude in the released slice.
- **WildChat-1M / -4.8M-Full** — *not used*: OpenAI-only.
- **LMSYS-Chat-1M / Chatbot Arena 33K** — *not yet evaluated*: multi-vendor
  Claude present; gated; pending.
